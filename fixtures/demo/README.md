# 시연용 fixture (fixtures/demo) — 설계 의도와 실제 결과

`rules.txt`(회칙 12조 + 공지 12건, 25문장)와 `kakao.txt`(PC 형식, 날짜선 6개 3월~9월, 메시지 166개 = 업무 48 + 잡담 118(노이즈 16 포함) → 파서 통과 150개).
골드셋 정답표의 초안으로 쓴다. **LLM 출력은 실행마다 조금씩 다르다.** 아래 "실제 결과"는 2026-11-13에 `claude-haiku-5-5`로 `dump.py`를 2회 돌린 값이고, 어긋나면 fixture 문장을 조정한다(프롬프트는 건드리지 않는다).

실행:
```bash
python scripts/smoke.py --base http://localhost:8000 --rules fixtures/demo/rules.txt --kakao fixtures/demo/kakao.txt --save out/smoke_demo.json
python scripts/dump.py fixtures/demo -o out/demo.json
```

### 편차가 있는 부분 (시연 대본을 쓸 때 주의)

- **B**: "월말쯤까지"를 근거로 볼지 말지가 실행마다 갈린다. 어느 쪽이든 회비 시기는 질문 후보에 들어간다(보완 또는 빈칸).
- 다른 항목에도 추정 사실이 0~1개 생길 수 있다(예: "연습용 코트 대관도 추가로 잡아뒀어요" → 5/23으로 짐작).
- score는 6개 항목이 5~6에 몰려 있어 2위 이하 순서와 카드 3~5번은 실행마다 바뀐다. **1위 장비 관리와 그 카드 2장은 고정**이다.
- 사실 수는 실행마다 64~83개로 달라진다(같은 메시지를 묶거나 나누는 차이).

## 잡담·노이즈 설계

- 잡담 118개: 수업·학식·시험·치킨·고양이 등. 업무 키워드(회비·대관·대회·모집·모임·장비)는 피했고, "코트 가고 싶다"처럼 일부러 섞은 것은 소수.
- 노이즈 16개: `사진` 8, `이모티콘` 8 → 파서가 제거해야 한다(메시지 166 → 150).
- 여러 줄 메시지 1개(6/9 태윤 "교수님이 공지 올리셨어요 / 7주차부터…") → 한 메시지로 합쳐져야 한다.
- 2학기부터 신입(26 서윤·26 도현) 등장 → 화자 수 변화.

## 조정 이력 (2026-11-13, 프롬프트는 그대로)

- 회칙의 운영진 구성·인수인계 조항 2개와 관련 카톡 2개 삭제 → 의도에 없던 "운영진 인수인계" 항목이 생기지 않게 함.
- 회칙·공지에서 정기 모임 문장과 코트 문장을 분리(공지 4/21 추가), 카톡도 "정기 모임 코트" 표현을 "코트 대관"과 "정기 모임"으로 나눔 → 두 업무가 한 항목으로 합쳐지지 않게 함.
- A: "시설과"·"신청"·"담당" 표현을 코트 관련 문장에서 모두 제거("잡아뒀어요", "확인증"). 이 단어가 하나라도 있으면 연락경로가 있음/추가확인권장으로 나왔다.
- B: 회칙 "매월 말까지"와 공지 "9월 말까지"를 빼고 카톡을 "월말쯤까지"·"이번 달 안에"로 바꿈. 기한이 문서에 있으면 시기가 확인됨으로 나왔다.
- C: 대회 외 날짜를 `월/일`로 적고, 대회 결과 잡담("8강까지 갔어요")을 일반 잡담으로 바꿔 추정 사실이 여러 개 생기던 것을 줄임.
- D: 장비 조항을 구체성 없는 두 줄로 줄임("분기마다 재고 점검", "회장 승인" 삭제).

## 금지어 체크 포인트

카톡에 "누락"·"잘못" 같은 단어를 **쓰지 않았다**. 질문 카드에 금지어가 나오면 fixture가 아니라 LLM 생성 문제이므로 재생성/템플릿 경로가 잡아야 한다.
