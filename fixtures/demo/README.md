# 시연용 fixture (fixtures/demo) — 설계 의도와 기대 결과

`rules.txt`(회칙 14조 + 공지 11건, 26문장)와 `kakao.txt`(PC 형식, 날짜선 6개 3월~9월, 메시지 166개 = 업무 50 + 잡담 116(노이즈 16 포함) → 파서 통과 150개).
골드셋 정답표의 초안으로 쓴다. **LLM 출력은 결정적이지 않으므로 아래 "기대"는 방향이고, 어긋나면 fixture 문장을 조정한다(프롬프트는 건드리지 않는다).**

실행:
```bash
python scripts/smoke.py --base http://localhost:8000 --rules fixtures/demo/rules.txt --kakao fixtures/demo/kakao.txt --save out/smoke_demo.json
python scripts/dump.py fixtures/demo -o out/demo.json
```

## 잡담·노이즈 설계

- 잡담 116개: 수업·학식·시험·치킨·고양이 등. 업무 키워드(회비·코트·대회·모집·모임·장비)는 피했고, "코트 가고 싶다"처럼 일부러 섞은 것은 소수.
- 노이즈 16개: `사진` 8, `이모티콘` 8 → 파서가 제거해야 한다(메시지 166 → 150).
- 여러 줄 메시지 1개(6/9 태윤 "교수님이 공지 올리셨어요 / 7주차부터…") → 한 메시지로 합쳐져야 한다.
- 2학기부터 신입(26 서윤·26 도현) 등장 → 화자 수 변화.

## 금지어 체크 포인트

카톡에 "누락"·"잘못" 같은 단어를 **쓰지 않았다**(첫 임시 fixture와 다름). 질문 카드에 금지어가 나오면 fixture가 아니라 LLM 생성 문제이므로 재생성/템플릿 경로가 잡아야 한다.
